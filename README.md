# 오픈니스 스튜디오 2026 하반기 채용 현황 페이지

인사팀이 실무팀에 전달하는 지원자 현황 웹페이지입니다. 비밀번호를 입력해야 열립니다.

## 구조

| 위치 | 내용 | GitHub |
|---|---|---|
| `docs/` | **게시용 배포본.** 개인정보가 있는 데이터·이미지는 모두 암호화되어 있음 | 올림 |
| `index.html`, `css/`, `js/` | 사이트 코드 (개인정보 없음) | 올림 |
| `scripts/` | 엑셀·PDF에서 데이터와 이미지를 만드는 스크립트, 암호화 빌드 | 올림 |
| `data/`, `assets/img/` | 지원자 개인정보가 담긴 **평문 원본** | **올리지 않음** (`.gitignore`) |
| `mockups/` | 시안 파일 (개인정보 포함) | **올리지 않음** (`.gitignore`) |

저장소가 공개(Public)이므로 평문 원본은 이 PC(OneDrive)에만 보관합니다.

## 배포본 만들기 (내용·비밀번호를 바꿀 때마다)

```bash
python scripts/build_secure.py
```

비밀번호를 입력창으로 묻습니다. 비밀번호는 파일 어디에도 저장되지 않으며, 입력한 비밀번호로 `docs/` 안의 데이터가 암호화됩니다.
비밀번호를 바꾸려면 새 비밀번호로 이 명령을 다시 실행하고 `docs/`를 다시 올리면 됩니다.

## 데이터 갱신 순서

1. 엑셀을 고치거나 `data/profiles.json`, `data/schedule.js`, `data/guide.js`를 수정
2. `python scripts/build_data.py "<엑셀 경로>"` (엑셀을 바꾼 경우)
3. `python scripts/build_secure.py`
4. `docs/` 변경분을 커밋·푸시

## GitHub Pages 설정

저장소 Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / 폴더 `/docs`

## 보안 참고

- 공개되는 파일에는 지원자 정보가 없습니다. 암호문과 코드만 올라갑니다.
- 4자리 숫자처럼 짧은 비밀번호는 암호문을 내려받아 대입 공격을 하면 풀릴 수 있습니다. 비밀번호가 길고 복잡할수록 안전합니다.
- 페이지에는 `noindex` 설정이 있어 검색엔진에 노출되지 않도록 요청하지만, 주소를 아는 사람은 비밀번호 입력 화면까지는 볼 수 있습니다.
