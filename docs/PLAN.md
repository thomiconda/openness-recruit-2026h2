# 2026 하반기 채용 지원자 현황 웹페이지 - 계획

## 목적
인사팀이 실무팀에 전달하는 지원자 현황·인적사항·지원자별 소개 페이지 (PC/모바일 대응).

## 확정 사항
- 정적 웹(HTML/CSS/JS), 서버·DB 없음. 로컬에서 index.html 더블클릭으로 실행, 완성 후 GitHub에 push해 GitHub Pages로 공개.
- 공개 방식: 전체 공개(방식 C). 단 연락처(010-1234-****)와 이메일(ab***@도메인)만 마스킹, 나머지 인적사항은 그대로.
- 포트폴리오 PDF 링크·원본 첨부 없음. 지원자별 대표 이미지 3~4장만 WebP로 변환해 삽입.
- 인사팀 코멘트·평가·우선 표시(☆/★) 없음.
- 디자인: 오픈니스 스튜디오/자연감각 포트폴리오 톤 참고(에디토리얼, 여백, 명조+돋움). 폰트는 무료 웹폰트로 대체.
- 데이터는 data/applicants.js (window.APPLICANTS). file:// 에서도 동작하도록 JSON fetch를 쓰지 않는다.
- 입력 엑셀은 1번 시트만 사용. 2번 시트(지난해 지원자)는 사용·게시하지 않는다.

## 메뉴
현황 / 지원자 목록 / 인적사항 / 지원자 상세 / 전형 일정 / 안내

## 단계
1. 데이터 정리 (완료: scripts/build_data.py -> data/applicants.js, 15명 마스킹 확인)
2. PDF 읽기: 지원자별 학력·경력·자격·핵심 역량 요약, 대표 이미지 선별·변환
3. 사이트 뼈대(메뉴·라우팅·반응형) + 현황·목록
4. 인적사항·상세·전형 일정
5. 검토, 모바일/인쇄 점검, GitHub push

## 주의
- 전체 공개이므로 이름·학력·거주지·작품 이미지가 인터넷에 공개됨(사용자 결정). 지원자 이미지는 본인 저작물.
- 자유서술 칸(비고)에 섞인 전화번호·이메일은 자동 제거(scrub).
